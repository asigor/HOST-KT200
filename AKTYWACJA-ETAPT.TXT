•	łączy się z autoryzowanym urządzeniem (HWID),

________________________________________
🚦 PRZEBIEG:
✅ 1. Klient wysyła żądanie GET:
GET /weblm/activation.php?code=HA38-KOQS-H44K&hwid=...&hash=...
Parametry:
Parametr	Znaczenie
code	Kod aktywacyjny
hwid	Unikalny identyfikator sprzętowy
hash	Sygnatura (HMAC-SHA1) wygenerowana po stronie klienta
________________________________________
🧠 2. Serwer generuje odpowiedź:
a) Łączy hwid + code → payload
b) Haszuje payload z kluczem key = b"b1k2d9s4":
signature = hmac.new(key, payload, hashlib.sha1).digest()
c) Koduje signature do Base64:
block = base64.b64encode(signature).decode()
________________________________________
📤 3. Serwer zwraca odpowiedź:
OK
<block>
Przykład:
OK
JGan4XScCoqC8HsolL8uUs7kCj0=
________________________________________
📄 Funkcja serwerowa (pełna):
import hmac
import hashlib
import base64

def generate_activation_response(code: str, hwid: str) -> str:
    key = b"b1k2d9s4"
    payload = (hwid + code).encode("utf-8")
    signature = hmac.new(key, payload, hashlib.sha1).digest()
    block = base64.b64encode(signature).decode("utf-8")
    return f"OK\n{block}"
________________________________________
🔒 Dlaczego to działa?
Bo klient po stronie .NET:
•	wykonuje te same operacje (HMACSHA1(hwid + code), Convert.ToBase64String(...))
•	i porównuje wynik z tym, co zwrócił serwer

def handle_handshake(query):
    hwid = query.get("id")
    length = query.get("len")
    name = query.get("name")
    version = query.get("vers")
    device_type = query.get("type")

    if not hwid or len(hwid) < 10:
