📦 1. CO TO JEST HMAC?

HMAC (Hash-based Message Authentication Code) to funkcja kryptograficzna, która:

używa tajnego klucza (secret key)

oraz funkcji haszującej (np. SHA1, SHA256)

aby wygenerować podpis danych (MAC)

📌 Używa się tego m.in. w:

tokenach autoryzacyjnych

aktywacjach offline

podpisach wiadomości

JWT (JSON Web Token)

klientach API

🔐 2. FORMAT HMAC

Wzór matematyczny:

HMAC(key, data) = H((key ⊕ opad) || H((key ⊕ ipad) || data))


Gdzie:

⊕ to XOR

opad = 0x5C * block size

ipad = 0x36 * block size

H to np. SHA1, SHA256

|| to konkatenacja

🔧 3. W Pythonie – użycie hmac (praktyka)
import hmac
import hashlib

h = hmac.new(b'secret_key', b'message', hashlib.sha1)
result = h.digest()     # bajty
hex_result = h.hexdigest()  # hex string


Lub:

block = base64.b64encode(h.digest()).decode()

🔁 4. hmac vs. zwykły hash
Zwykły hash (SHA1)	HMAC
hashlib.sha1(data)	hmac.new(key, data, hashlib.sha1)
Nie zabezpiecza przed manipulacją	TAK, zabezpiecza
Łatwy do złamania	Trudny do podrobienia
Brak tajnego klucza	Tajny klucz wymagany

LINIA 7:
signature = hmac.new(key, payload, hashlib.sha1).digest()

📦 PEŁNA LOGIKA – L I N I A 7

To najważniejsza operacja w całej funkcji – tutaj generujemy podpis HMAC-SHA1, który trafia do klienta jako block.
Ten podpis potwierdza integralność i autentyczność odpowiedzi serwera.

🧠 Co robi ta linia?
🔨 Krok po kroku:

hmac.new(...)

Tworzy nowy obiekt HMAC

Parametry:

key: bajty (tajny klucz)

payload: bajty (dane do podpisania)

hashlib.sha1: funkcja haszująca (SHA1)

.digest()

Oblicza podpis (MAC)

Zwraca surowe bajty (20 bajtów)

🔐 Co zawiera signature?

Wartość typu bytes:

b'\x24\x9a\xa7\xe1t\x9c\n\n\x82\xf0{\x28\x94\xbf.R\xce\xe4\n='


To wynik działania:

HMAC_SHA1(key=b"b1k2d9s4", data=b"eAaMKYle...HA38-KOQS...")

🧪 Jak sprawdzić wynik?

Możesz użyć:

print(signature.hex())


lub zakodować go do base64:

base64.b64encode(signature).decode()


W Twoim przypadku:

"JGan4XScCoqC8HsolL8uUs7kCj0="

🔁 Dlaczego .digest(), a nie .hexdigest()?
Metoda	Zwraca	Użycie
.digest()	surowe bajty (binary)	✅ używane do base64
.hexdigest()	tekst hex (np. a1b2c3...)	❌ niezgodne z klientem

📌 Musimy użyć .digest(), żeby przekazać wynik dalej do base64.b64encode(...).

❗ Co się stanie, jeśli hash się nie zgadza?

Klient oblicza swój HMAC lokalnie

Porównuje z tym, co dostał z serwera (block)

Jeśli nie są identyczne — przerywa aktywację

🔎 LINIA 8:
block = base64.b64encode(signature).decode("utf-8")

📦 PEŁNA LOGIKA – L I N I A 8

Ta linia zamienia wcześniej wygenerowany surowy podpis HMAC (bajty) w czytelną postać Base64, którą można wysłać do klienta.
To dokładnie to, co klient .NET odczytuje jako block i sprawdza zgodność z własnym podpisem.

🔍 Co robi ta linia?
Krok po kroku:

base64.b64encode(signature)

Zamienia surowe bajty (bytes) z SHA1 na base64 zakodowany ciąg bajtów

Przykład:

b'$\x9a\xa7\xe1t\x9c\n\n\x82\xf0{\(...)\x8a=' → b'JGan4XScCoqC8HsolL8uUs7kCj0='


.decode("utf-8")

Konwertuje z bytes do str – potrzebne do wstawienia w odpowiedź HTTP

Bez .decode() byłby to np. b'JGan4XSc...', co spowoduje błąd przy zwracaniu stringa

🧪 Przykład:
signature = b'\x24\x9a\xa7\xe1t\x9c\n\n\x82\xf0{\x28\x94\xbf.R\xce\xe4\n='
block = base64.b64encode(signature).decode("utf-8")
print(block)
# → "JGan4XScCoqC8HsolL8uUs7kCj0="

⚠️ Dlaczego to musi być Base64?

Klient .NET oczekuje:

OK
JGan4XScCoqC8HsolL8uUs7kCj0=


Surowy digest() wyglądałby jak krzaki (np. \x9a\xa7...)

Base64 jest:

czytelny

bezpieczny do przesyłu przez HTTP

kompatybilny z klientem, który też używa Convert.ToBase64String(...)

✅ Co robi .decode("utf-8")?

Bez tego, Python zwróci bytes, np.:

b'JGan4XSc...'


A odpowiedź HTTP wymaga typu str, więc:

"OK\nJGan4XSc..."

🧱 Alternatywy:
Metoda	Wynik
base64.b64encode(signature)	b'JGan4XSc...' (bytes)
... .decode()	'JGan4XSc...' (str ✅)
signature.hex()	'249aa7e1749c0a0a...' (❌ klient nie rozpozna)
❌ Co się stanie bez .decode()?

W zwrotce serwera:

return f"OK\n{block}"


Dostaniesz wyjątek:

TypeError: can only concatenate str (not "bytes") to str
