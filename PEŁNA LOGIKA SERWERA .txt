🧠 1. DEFINICJA BLOBA (zgodnie z HoneyDataProcessor.cs + ExtractedData.cs)

Bloby to zaszyfrowane dane (Base64 + XOR + UTF-8), pobierane z Honey.bin.
Dekodowanie wygląda tak:

// Dekodowanie z Honey.bin:
string base64 = File.ReadAllText("Honey.bin");
byte[] xorDecoded = base64.Select(b => (byte)(b ^ 0x55)).ToArray();
string json = Encoding.UTF8.GetString(xorDecoded);


🧩 Więc BLOB = Base64( XOR(UTF8(JSON)) )

📦 2. PRZYKŁADOWY BLOB (INFO_INIT2024)

Kodowanie tego bloba:

string json = JsonConvert.SerializeObject(data);             // UTF-8
byte[] xor = json.Select(c => (byte)(c ^ 0x55)).ToArray();   // XOR 0x55
string final = Convert.ToBase64String(xor);                  // Base64

🔐 3. FUNKCJA: GENERATOR BLOBA (.NET / C#)
public static string GenerateBlob(object data)
{
    string json = JsonConvert.SerializeObject(data);
    byte[] raw = Encoding.UTF8.GetBytes(json);
    byte[] obfuscated = raw.Select(b => (byte)(b ^ 0x55)).ToArray();
    return Convert.ToBase64String(obfuscated);
}

📤 4. DEKODER BLOBA (HoneyDataProcessor.cs)
public static string DecodeBlob(string base64)
{
    byte[] raw = Convert.FromBase64String(base64);
    byte[] deob = raw.Select(b => (byte)(b ^ 0x55)).ToArray();
    return Encoding.UTF8.GetString(deob);
}
